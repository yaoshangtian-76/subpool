# subpool

多源订阅聚合 + 内核真连接实测，只输出实测可连的节点。

## 输出
- `output/clash.yaml` —— Clash / mihomo 订阅
- `output/v2ray.txt` —— base64 v2rayN 订阅

## 订阅地址
- https://raw.githubusercontent.com/yaoshangtian-76/subpool/main/output/clash.yaml
- https://cdn.jsdelivr.net/gh/yaoshangtian-76/subpool@main/output/clash.yaml

## 私有订阅源
仓库 Settings → Secrets and variables → Actions → New repository secret，名称填 `SUBS`，值为逗号分隔的订阅链接。

## 说明
Actions 出口在境外，实测结果反映"境外出口可达"，不等于国内宽带可直连。
